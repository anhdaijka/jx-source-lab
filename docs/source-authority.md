# Source Authority & Evidence Policy

## Default authority
Implementation facts: matching raw server/client build → matching first-party docs → archived first-party → other-edition implementation as comparison.
Producer-intent/lore: Kingsoft/Xoyo first-party → matching official game data/dialogue → VNG official localization/publication → archived official.
Community/fan = lead only.

## Distinction
A raw private/later build proves `this build contains X`, not automatically `launch-era official canon intended X`.

## Confidence
`VERIFIED_DIRECT`, `VERIFIED_CROSS_SOURCE`, `STRONG`, `INFERENCE`, `UNKNOWN`, `CONFLICT`, `EDITION_DRIFT`.
Only the first three are normally promotable, and `STRONG` must state its basis.

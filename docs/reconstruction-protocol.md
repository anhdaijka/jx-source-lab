# Game Story Reconstruction Protocol

## Goal
Produce a human-readable reconstruction of what actually happens in the game without novelizing missing material.

## Per quest family
1. Parent task / route gate
2. Ordered dependencies
3. Exact task names
4. Giver / turn-in NPCs
5. Start / progress / completion dialogue
6. Objectives / target NPCs / mobs / items / maps
7. Script callbacks / flags / state writes / rewards
8. Next-task transitions
9. Official chronology/lore cross-check
10. Edition contradictions
11. Causal reconstruction
12. Explicit unresolved questions

## Dossier sections
Identity/route; source scope/edition; prerequisites; characters; factions; locations; items; named martial arts if evidenced; ordered implementation events; dialogue-backed beats; what player learns; evidenced faction goals; reveal; climax/completion; immediate/downstream consequences; official context; drift; UNKNOWN; claim-evidence table.

## Hard prohibition
A title such as `Bí Mật Đê Vỡ` alone does not establish who broke the dike, how, why or who ordered it.

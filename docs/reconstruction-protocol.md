# Game Story Reconstruction Protocol

## Goal
Produce a human-readable reconstruction of what actually happens in Kiếm Thế, targeting the **latest coherent lore supported by the combined corpus**, without novelizing missing material.

The goal is narrative reconstruction, not exact client/server version archaeology. A community-modified build is acceptable evidence when its story-bearing content remains consistent with the wider lore corpus.

## Per quest family
1. Parent task / route gate
2. Ordered dependencies
3. Exact task names
4. Giver / turn-in NPCs
5. Start / progress / completion dialogue
6. Objectives / target NPCs / mobs / items / maps
7. Script callbacks / flags / state writes / rewards when narratively relevant
8. Next-task transitions
9. Wider lore/chronology cross-check using Kingsoft/Xoyo/VNG/archived official material where available
10. Narrative-significant contradictions or drift
11. Causal reconstruction
12. Explicit unresolved questions

## Dossier sections
Identity/route; source scope; prerequisites; characters; factions; locations; items; named martial arts if evidenced; ordered implementation events; dialogue-backed beats; what player learns; evidenced faction goals; reveal; climax/completion; immediate/downstream consequences; wider lore context; material drift; UNKNOWN; claim-evidence table.

## Priority rule
Spend effort where it improves the novel source base: central causality, character motives, faction goals, reveal order, political stakes, named martial arts, named items, locations and consequences.

Do not spend significant effort resolving build/version differences that have no narrative consequence.

## Hard prohibition
A title such as `Bí Mật Đê Vỡ` alone does not establish who broke the dike, how, why or who ordered it.
